How a match is judged

The judge reads every match twice.

Models can favour whoever comes first. So Matchplay shows the pair in one order, then swaps them. A winner only counts when both readings agree.

  • 1The bar comes first. An entry earns something only when it clears the host's bar on its own. The lower of its two fit scores counts.
  • 2Both clear it? The winner must be the same in both orders. If the order changes the winner, the match is a tie.
  • 3Cheating costs the bond. A page that tries to steer the judge earns a strike, and the bond is forfeited.
One round, four moves

From mission to payout, all on chain.

Anyone can run the steps that need no trust. Only the host decides who is turned away, and only before the round starts.

1

Host opens

Attach the prize, set the mission, the bond, the bar and the clocks.

2

Entrants join

Pitch plus an evidence link, and exactly the entry bond. 3 to 8 entries.

3

Matches run

Anyone triggers the next match. Each pair meets once, each is read twice.

4

Payout

Points times the price of a point, plus the bond back. What nobody earns returns to the host.
